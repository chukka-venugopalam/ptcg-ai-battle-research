# Repository Data and License Boundary

This working repo combines authored notes/scripts with third-party research references, competition submission archives, trained weights and competition SDK assets. They do not all share the same license.

- No blanket license is granted to every file in this repository.
- `local_data/` is ignored by Git and may contain official competition packages, screenshots, third-party source bundles or private inputs. Keep it local unless you have permission to redistribute.
- `submissions/archive/*.tar.gz` contain model weights and bundled engine/runtime files. Keep the Git remote private by default; verify all terms before making it public.
- Research summaries should cite/record original URLs and repository commit/license before third-party code is incorporated.
- Never commit Kaggle credentials, API tokens, private replay data or personal account information.
