# Final submission area

Only runtime assets required by `main.py` belong here.

The competition contract requires `main.py` and `deck.csv` at the root of the `.tar.gz` archive. Additional local model files are allowed only when the runtime needs them and they fit the submission limit.

Build:

```bash
bash submission/build_submission.sh
```

Never submit the research dataset, notebooks, source repositories, replay archives, training logs, or the full development simulator unless the competition rules explicitly require them.

## Historical artifacts

Submitted archives are kept outside this runtime folder under
`submissions/<date>/`.
