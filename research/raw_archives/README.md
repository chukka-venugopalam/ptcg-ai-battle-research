# Raw archives

The ZIPs here are kept unchanged from the research runs. Extracted working copies live in `research/missions/`. Raw mission archives may contain fixture-agent logs or synthetic test evidence; consult each mission's own report and do not label fixture games as actual competitive-agent results.

Large/permission-sensitive original bundles and official competition SDKs remain in `local_data/private_inputs/` and are excluded from Git by `.gitignore`.
