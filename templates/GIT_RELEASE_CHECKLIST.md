# Git Release Checklist

- [ ] `git status` reviewed; no secrets or unintended local inputs staged.
- [ ] Submission hash recorded in the registry and report.
- [ ] `python tools/validate_submission.py <archive>` passes.
- [ ] All actual experiments have row-complete evidence files and predeclared protocol.
- [ ] Any tournament claims clearly separate screening from confirmation.
- [ ] License/privacy review completed before a public push.
- [ ] Commit uses a descriptive message; candidate is not promoted to `current/` without the promotion gate.
